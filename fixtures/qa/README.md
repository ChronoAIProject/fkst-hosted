# Local QA Fixtures

This directory owns synthetic, non-secret Local QA fixtures. The current
language-neutral contract corpus is `contract-foundation-v1.json`; it defines
stable validation, rejection, canonical-byte, digest, and projection case IDs
for the P0-02 contract foundation.

The directory still contains no executable project, guest image, Secret
material, runtime artifact, browser fixture, or normative side-effecting
example. Each future fixture class needs a dedicated issue and must remain inert
during installation and validation.
